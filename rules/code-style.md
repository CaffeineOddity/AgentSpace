# 代码风格

- 注释一律用中文。
- 优先函数式编程，OOP 仅用于连接器与外部系统接口。
- 写纯函数：只改返回值，绝不修改入参或全局状态。
- 遵循 SOLID、OCP、LSP、DIP、DRY、KISS、YAGNI。
- 优先简单、原生、官方推荐的方案，避免过早抽象。
- 严格类型：返回值、变量、集合、复杂数据一律显式标注；外部/API 数据运行时校验；
  需要的字段必填、无关字段忽略，优先结构化模型而非松散字典；
  避免 `Any`、`unknown`、`Record<string, any>` 等弱类型。
- 写新代码前先确认是否已有现成逻辑可复用。
- 禁用默认参数值，所有参数显式传递。
- 函数单一职责、单模式行为；禁止 flag 参数切换逻辑；
  用户需要多种模式时应显式提出。
