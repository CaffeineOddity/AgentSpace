# 插画系统规范

> 本文件是产品插画系统设计的唯一事实来源。品牌吉祥物/IP 角色设计见 `specs/brand` 的 B6 章节，本 spec 覆盖产品界面内的功能插画（空状态、引导页、功能说明、错误页、加载动画）以及文章内容配图。

## 设计目标

为产品各端（Web/iOS/Android/鸿蒙）产出风格统一、场景适配、功能明确的功能插画系统。核心矛盾是「视觉吸引力」与「功能克制」的平衡--功能插画不是艺术品，是在用户需要时出现、传达信息或缓解焦虑、然后退场的辅助角色。

功能插画解决三个问题：**空状态不再冰冷**（无数据时给用户方向而非空白）、**引导更直观**（图文比纯文字更易理解）、**错误更温暖**（出错时降低挫败感）。

## 插画场景清单

| 场景 | 用途 | 情绪基调 |
|------|------|---------|
| 空状态 | 列表无数据、搜索无结果、无权限 | 安抚 + 引导行动 |
| 引导页 | 首次使用、功能介绍、权限请求 | 友好 + 期待 |
| 错误页 | 网络错误、服务器错误、404 | 克制 + 提供出路 |
| 加载 | 骨架屏替代、下拉刷新、内容加载中 | 活跃但不焦虑 |
| 成功 | 操作完成、支付成功、提交成功 | 庆祝但不夸张 |
| 功能说明 | 复杂功能图解、权限说明 | 清晰 + 信任 |
| 文章配图 | 文章内文插图、章节配图、流程图解、概念图 | 辅助阅读 + 不喧宾夺主 |

## 操作流程

### I1. 风格定义

确定插画系统的视觉风格，须与品牌人格一致（见 `specs/brand` 的 B1 品牌解构）：

| 风格 | 特征 | 适用品牌人格 |
|------|------|-------------|
| 扁平 | 纯色块、无渐变、几何形 | 专业、效率、科技 |
| 线性 | 统一线宽、轮廓为主、留白多 | 极简、精致、高端 |
| 等距 | 45°视角、立体几何 | 技术、数据、产品 |
| 轻拟物 | 微渐变、柔阴影、有质感 | 温暖、友好、消费 |
| 角色/IP | 品牌吉祥物为主角 | 亲切、活泼、年轻 |

- 一种风格贯穿所有插画场景，不混用
- 线宽统一（如全部 2px 或全部 3px），同一视觉层级不混粗细
- 色彩从 `specs/brand` 的品牌色板取色，不自定义新色
- 暗色模式需独立适配（线条色/背景色/填充色调整），不是简单反色

### I2. 比例与网格

定义插画的标准画布与构图网格：

- 画布比例：1:1（方形场景）和 4:3（横版场景）为主
- 安全区：核心元素内缩 10%，边缘留呼吸空间
- 人物/主体比例：统一（如头部占画面 1/4），不忽大忽小
- 留白原则：插画在 UI 卡片内占比不超过 40%，给文字和操作留空间；占比按渲染后实测（插画区高/卡片高），且在演示所用各视口下都须达标，不以单一尺寸的理论估算为准

### I3. 色彩约束

| 角色 | 取色来源 | 约束 |
|------|---------|------|
| 主色 | 品牌主色 | 占插画面积 30-50% |
| 辅色 | 品牌辅色/色阶 | 支撑主色，20-30% |
| 中性色 | 品牌中性色阶 | 背景/线条/文字 |
| 语义色 | 品牌/平台功能色 | 成功绿、错误红等，须配图标 |

- 禁用品牌色板外的颜色（保证与品牌一致）；**「已记入色板」必须有载体文件**（如 `assets/<品牌>-palette.json`，亮色 hex + 暗色映射成对登记）——注释/SELF-CHECK 里声称「已登记」而无文件即摆拍
- 暗色模式：主色降饱和提亮度，背景反色，线条提亮；**暗色映射值（提亮后的主色/反色背景）也要登记进品牌色板文档**，否则「板外色禁令」与「暗色必须换值」两条规则合用时必然矛盾
- 对比度：插画与背景文字组合须满足各端 a11y 要求

### I4. 空状态插画

空状态是最高频的插画场景。每张空状态插画须含：

- 插画主体（传达场景情绪）
- 标题（一句话说明现状，如「还没有内容」）
- 引导文案（一句话给出行动方向，如「点击这里创建第一条」）
- 行动按钮（可选，直接提供操作入口）

约束：

- 插画不遮挡行动按钮
- 情绪不过度悲伤/焦虑，空状态是正常状态不是错误
- 图标 + 文字 > 纯插画（可访问性）

### I5. 引导页插画

首次使用或功能介绍时出现：

- 每页一个核心功能点，不超过 3 页
- 插画 + 一句标题 + 一句说明
- 页面指示器（进度点/条）
- 跳过按钮始终可见
- 最后一页是行动入口（「开始使用」）

### I6. 加载动画

替代骨架屏或 spinner 的动画插画：

- 循环时长 1-2 秒，无缝衔接
- 动效引用 `specs/motion` 的时长/缓动 Token
- 尊重 reduced-motion，降级为静态插画 + 文字
- 不致焦虑（避免急促闪烁，用平缓的呼吸/浮动/旋转）

### I7. 文章内容配图

文章内文配图与产品 UI 插画不同：不受平台比例与安全区约束，核心是辅助阅读、打破文字墙、保持系列一致性。情绪基调是「辅助阅读 + 不喧宾夺主」--配图服务于文字，不是文字服务于配图。

#### 配图类型

| 类型 | 用途 | 比例建议 |
|------|------|---------|
| 章节配图 | 标记章节起始，烘托主题 | 16:9 或 21:9（横幅） |
| 流程图解 | 解释操作步骤、数据流向 | 4:3 或 16:9 |
| 概念图 | 抽象概念的可视化（如架构、关系） | 1:1 或 4:3 |
| 数据图 | 图表化数据（柱状/折线/饼图） | 16:9 或 4:3 |
| 分割装饰 | 段落间的视觉间隔 | 21:9 或自定义（细长） |
| 步骤标注 | 编号 + 插图，引导操作顺序 | 1:1 |

#### 图文混排规则

- 配图在文章流中独占一行，不与正文文字并排重叠
- 配图上下留白：上方 ≥ 1.5 倍行高，下方 ≥ 1 倍行高
- 全宽出血图：左右贴边，上下加 padding；内嵌图：左右内缩，有边框或圆角
- 配图须有图注（图下方小字，说明图的内容或来源），格式如「图 1：用户操作流程」
- 连续多张配图之间留 1 倍行高间距，不紧贴

#### 系列一致性

一篇文章内多张配图须保持视觉统一：

- 同一插画风格（扁平/线性/等距），不混用
- 同一色彩范围（取自品牌色板，主色占比 30-50%）
- 同一线宽（如全部 2px）
- 同一人物/主体比例（如有角色出现，比例统一）
- 同一构图逻辑（如全部居中对称，或全部左对齐）
- 图注样式统一（字号/颜色/位置）

#### 文字可读性

- 配图内文字（如有标注）字号 ≥ 14px，与配图背景对比度 ≥ 4.5:1
- 配图不替代正文--关键信息须在正文中用文字说明，配图是辅助
- 流程图解的节点文字简洁，一句话一个节点
- 数据图的轴标签/数值标签须清晰可读

#### 与封面的区别

| 维度 | 文章配图（本节） | 文章封面（`specs/cover`） |
|------|----------------|----------------------|
| 位置 | 文章内文 | 文章顶部/信息流缩略图 |
| 约束 | 无平台比例约束 | 按平台比例 + 安全区 |
| 目标 | 辅助阅读、打破文字墙 | 吸引点击、传达主题 |
| 文字 | 图注辅助，不喧宾夺主 | 标题排版为核心 |
| 导出 | PNG/JPG/SVG 视风格 | JPG/PNG 按平台 |

### I8. 导出

**可审阅插画集 HTML**（首选）：单页 HTML，将整套插画并排展示供风格一致性审阅

- 按场景分组（空状态/引导/错误/加载/成功/文章配图），每场景一个区块
- 每插画一格：插画预览 + 场景 + 风格 + 色彩来源 + 情绪基调
- 弹出式审阅（见 `specs/review`）：每插画格有 [+] 按钮，点击弹窗写反馈 + 快捷标记
- 支持导出 Markdown/JSON 给 AI 修改，保留上一轮反馈对比
- 用于独立插画系统任务或项目流程中的插画审阅检查点

**正式导出文件**：

| 格式 | 用途 |
|------|------|
| SVG | 矢量格式（可选），各端通用、支持主题着色；**不做强制要求** |
| GIF | 简单循环动画/表情便捷格式，跨端通用 |
| PNG | 静态插画通用格式；透明背景插画普遍首选 |
| JPG | 照片质感/文章配图/无透明需求的场景 |
| Lottie JSON | 复杂动画插画（After Effects 导出），按需 |
| WebP | Web 端有动画需求时（可选） |

- **格式不强制 SVG**：应根据插画风格与呈现方式选择最合适的格式——写实/笔触/照片质感/需 AI 生成（`scripts/toapis.py`）的插画，用 **PNG / JPG / GIF** 更自然、更佳；SVG 仅在有内联・主题着色・矢量需求时选用
- 动效插画可选 GIF / Lottie；静态插画选 PNG / JPG / SVG
- 命名：`ill_empty_<场景>.png/.jpg/.gif/.svg`、`ill_loading_<场景>.json`
- 按 `specs/mobile` 的切图命名规范，文件系统兼容

插画集 HTML 定稿后导出正式 PNG/JPG/GIF/SVG/Lottie 文件。

## 验收标准

- [ ] 一种风格贯穿所有插画场景，不混用
- [ ] 线宽统一，同层级不混粗细
- [ ] 色彩全部取自品牌色板，无色板外颜色（暗色适配的映射值视作色板的暗色分支，须与亮色值一并记入色板文档，不算板外色）
- [ ] 暗色模式独立适配，对比度达标
- [ ] 每张空状态含插画 + 标题 + 引导文案 + 行动按钮
- [ ] 引导页 ≤ 3 页，每页一个功能点
- [ ] 加载动画无缝循环 1-2 秒，尊重 reduced-motion
- [ ] 静态插画选 PNG/JPG/SVG 中与风格最契合的格式，不强制 SVG
- [ ] 动画插画可用 GIF 或 Lottie
- [ ] 插画在 UI 卡片内占比 ≤ 40%
- [ ] 命名遵循 `ill_<场景>_<用途>` 规范
- [ ] 文章配图：同篇多图风格/色彩/线宽/比例统一
- [ ] 文章配图：上下留白达标（上 ≥ 1.5 倍行高，下 ≥ 1 倍行高）
- [ ] 文章配图：每张有图注
- [ ] 文章配图：图内文字 ≥ 14px，对比度 ≥ 4.5:1

## 边界与不做项

- 品牌吉祥物/IP 角色设计见 `specs/brand` 的 B6 章节
- 动效 Token 引用 `specs/motion`，本 spec 不重新定义
- 封面/头图设计见 `specs/cover`，本 spec 仅覆盖产品界面内插画及文章内文配图
- 文章封面（公众号头图、小红书封面、YouTube 缩略图等）见 `specs/cover`，不在此处
- Token 架构与组件化见 `specs/design-system`，插画资源导出归属各端切图规范
- 插画的代码集成（SVG 内联/Lottie 库/PNG·GIF 资源引用）由开发负责
