# 品牌视觉系统设计规范

> 本文件是品牌视觉系统（Brand Identity System）设计的唯一事实来源。所有品牌产出须通过文末验收清单。品牌 spec 是跨端一致性的锚点。

## 设计目标

产出完整的品牌视觉识别系统，使品牌在 Web、移动端、物料、IP 形象等所有触点保持高度一致的视觉语言。核心是「一套基线，多端复用」--品牌 spec 定调，各端 spec 定规。

品牌系统不是 Logo 加配色，是让用户在任何触点都能认出「这是同一个品牌」的完整规则集。

## 操作流程

色彩与字体以 `design/output/direction.md` 为准。本 spec 把已确认的参考落成色板、字体层级和手册。

### B1. 品牌解构

提取品牌核心：

- 品牌名称 / 产品名
- 行业 / 品类
- 核心价值词汇（如「可信、专业、有温度」）
- 风格关键词（如「极简科技感」）
- 目标受众
- 品牌人格（如果品牌是一个人，是什么性格）

缺失项主动追问。品牌人格决定后续所有视觉选择的基调。

### B2. Logo 设计与安全空间

- 主输出为 SVG，保证任意缩放不失真且路径可编辑
- 基于品牌人格选择造型方向（几何 / 有机 / 字标 / 图形标 / 组合标）
- 定义安全空间：Logo 周围不可侵入的最小留白（通常用 Logo 高度的 1/4 或 1/2 度量）
- 定义最小可用尺寸，确保小尺寸下仍可识别
- 提供正/反/单色/纯色底反白等变体
- SVG 须标准规范、无外部字体依赖、转曲

### B3. 品牌色彩体系

建立主色 + 辅色 + 色阶的完整体系：

| 角色 | 用途 | 示例 |
|------|------|------|
| 主色 | 品牌识别核心，用于 Logo、主操作 | 占比最大或最突出 |
| 辅色 | 支撑主色，用于次级元素 | 与主色互补或邻近 |
| 强调色 | 锐利点缀，用于 CTA、高亮 | 小面积高对比 |
| 中性色 | 文本、背景、边框 | 灰阶 |
| 功能色 | 错误/成功/警告 | 须配图标或文字 |

- 每个色定义语义名 + hex + 用途，不裸用 hex
- 提供暗色模式降饱和变体
- 色彩对比度须满足各端无障碍要求（见各端 spec）
- 输出色板文件（.ase / JSON Token）

### B4. 专用字体层级

定义品牌专用字体系统：

| 层级 | 用途 | 字重 |
|------|------|------|
| 展示字体 | 主标题、品牌名、大字号场景 | 600-700 |
| 正文字体 | 正文、说明、列表 | 400 |
| 标签字体 | 按钮、标签、数字 | 500 |

- 展示字体须有性格，避免泛用族（Inter/Roboto/Arial）
- 正文优先可读性
- 字体配对：性格互补，不冲突
- 定义完整字号阶梯（如 12/14/16/18/24/32/48）
- 数字用 tabular figures
- **手册「实际字体渲染」须真实加载**：声明的 webfont 无 @font-face/link 加载机制时，页面渲染的是回退字体而非声明字体，「实际渲染」不成立；须有加载机制或显式标注回退（与 `specs/design-system`/`specs/web` 字体加载条款同源）
- **Logo 变体用色入板**：单色/反白等变体源文件（含 SVG fill/stroke）的色值须在色板内定义，禁游离色；反白变体用专用源文件，禁 CSS `filter:invert` 拼贴（会把非中性色一并反转脱离规范色域）
- **色值承载文字须过 AA**：品牌色上叠白字/深字的组合（CTA、徽标）须对比度 ≥4.5:1（小字）；不够时在色板定义加深/减淡档（如 `accent-deep`）供文字场景引用

### B5. 辅助图形与底纹

- 辅助图形从 Logo 或品牌人格延伸，保持视觉血缘
- 用于背景、分隔、装饰、空状态插画
- 定义铺贴规则（平铺 / 流动 / 定点）
- 底纹不可喧宾夺主，内容可读性优先

### B6. IP 形象体系

当品牌需要 IP 角色时**必须实际生成并交付形象素材**，不能用占位、不用文字描述替代产出：

- 定义 IP 基础形象（三视图：正面/侧面/背面）
- 使用 `scripts/toapis.py` 生成真实形象素材（PNG/JPG/GIF），`--background transparent` 出透明底便于多端嵌入；生成前按 `specs/image-prompt` 先写 `xxx_prompt.md`
- 保持角色特征在所有输出中一致
- 生成至少 12 种常用表情（开心/生气/疑惑/期待/加载中/点赞/搜索无结果等）
- 表情输出为透明通道序列帧、APNG/WebP，或 **GIF 动画表情**（轻量、跨端通用）+ 静态 PNG
- 定义 IP 使用场景（空状态、引导页、消息气泡、加载动画）
- IP 不可遮挡关键操作元素

### B7. 品牌应用示例

展示品牌在各触点的应用，证明系统可用：

- 名片、信纸、工牌
- 社交媒体头像、封面
- 包装、周边
- Web 官网头部
- App 启动图与图标

应用示例是品牌系统的压力测试--若某触点无法自洽应用，说明系统有缺口。

### B8. 品牌规范手册

整合以上为可交付手册，不少于 8 页。产出为可审阅 HTML 单页，弹出式审阅（见 `specs/review`）：

1. 标志释义与安全空间
2. 品牌色彩体系（色板可视化 + hex + 语义名 + 暗色模式切换）
3. 专用字体层级（实际字体渲染 + 字号阶梯预览）
4. 辅助图形 / 底纹（铺贴效果演示）
5. IP 形象三视图与表情变体（须 `scripts/toapis.py` 生成真实素材）
6. 品牌应用示例（可用 `scripts/toapis.py` 生成）
7. 插画风格指引
8. 禁忌示例

产出格式：

- **可审阅 HTML**（首选）：单页 HTML，每区块弹出式审阅输入框 + 快捷标记，支持导出 Markdown/JSON 给 AI 修改，保留上一轮反馈对比
- **PDF 导出**（可选）：HTML 定稿后可导出 PDF 用于打印/分享
- **素材文件夹**：SVG 标志、色板（.ase）、字体指引

在 workflow 中，品牌规范手册 HTML 是 Phase 3 的产出之一（见 `specs/workflow` 的 Phase 3）。

### B9. 禁忌示例

明确不可做的事，与正面示例对照：

- Logo 不可拉伸变形、不可改色、不可加投影（除非规范允许）
- 色彩不可随意组合、不可用未定义色
- 字体不可替换为未定义字体
- IP 不可在不同场景特征不一致
- 不可将辅助图形用于与品牌人格冲突的场景

## 验收标准

- [ ] Logo 为 SVG，标准规范、转曲、无外部字体依赖（判定对象：**交付级 Logo 源文件**须纯 path 转曲；审阅 HTML 展示层的 `<text>` 标注不在此限）
- [ ] 安全空间已定义并标注
- [ ] 色彩体系含主/辅/强调/中性/功能色，每色有语义名 + hex + 用途
- [ ] 暗色模式变体已定义
- [ ] 字体层级含展示/正文/标签三层，非泛用族单一方案
- [ ] 字号阶梯完整
- [ ] 辅助图形从 Logo 或品牌人格延伸，铺贴规则已定义
- [ ] IP 形象三视图 + ≥ 12 表情，特征一致，为 `scripts/toapis.py` 生成的真实素材（PNG/JPG/GIF，透明底或 GIF 动画）
- [ ] IP 素材以本 spec B6 为唯一事实来源执行，不得以文字描述/占位替代实际生成
- [ ] 品牌应用示例覆盖 ≥ 4 个触点
- [ ] 规范手册 ≥ 8 页，含禁忌示例
- [ ] 品牌系统各页面视觉偏差 < 5%（**可执行定义**：所有页面同一角色取值（色彩 hex/字号/间距/圆角）与色板、Token 文件逐项 diff，取值不一致的项数 ≤ 总项数 5%；不做像素比对）
- [ ] 色板与字体指引可独立交付（.ase / JSON / 字体文件指引）
- [ ] 手册声明字体真实加载或显式标注回退；Logo 全部变体（含 SVG 源文件）用色在色板内；文字承载色组合 ≥4.5:1 或色板提供可用的加深/减淡档

## 边界与不做项

- 不负责品牌策略与市场定位（本规范是视觉层）
- 不负责文案撰写与品牌故事
- Web/移动端具体平台适配见各自 spec
- 品牌基线注入各端的机制见 `specs/spec-customization`
- IP 表情与 App 页面的融合合成见 `specs/mobile` 的切图与资源流程
