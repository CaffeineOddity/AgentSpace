# 鸿蒙设计规范（HarmonyOS UX）

> 本文件是鸿蒙（HarmonyOS）平台设计的深潜参考。跨端共用部分见 `specs/mobile/mobile-design.md`，品牌基线见 `specs/brand`。读 `mobile-design.md` 时按目标平台路由到本文件。

## 设计目标

遵循 HarmonyOS UX Design 规范，产出符合华为设计语言的界面。鸿蒙区别于 iOS/Android 的核心理念：

- **一多（一次开发多端部署）**：同一界面自适应手机/平板/手表/智慧屏/车机
- **分布式**：服务可在多设备间流转，UI 须支持跨设备续接
- **服务卡片**：将应用核心功能以卡片形态置于桌面/服务中心，无需进入应用
- **纯净简约**：信息密度适中，留白充足，动效自然

## 设计语言要点

### 导航结构

| 模式 | 用途 |
|------|------|
| Tab | 顶层导航，底部或顶部，≤ 5 项 |
| 侧入口（Side Bar） | 二级导航，左侧可展开 |
| 返回 | 全局返回，支持手势返回 |
| Sheet | 模态临时任务，下拉关闭 |

- Tab 优先底部，内容型应用可用顶部 Tab
- 侧入口用于设置/个人中心等二级页面
- 全局返回行为可预测，保留滚动与状态
- 大屏设备（平板/智慧屏）可用分栏布局

### 排版系统

鸿蒙字阶，遵循系统字重层级：

| 角色 | 用途 |
|------|------|
| Title（大/中/小） | 页面/区块标题 |
| Subtitle | 副标题 |
| Body（大/中/小） | 正文 |
| Caption | 说明/辅助 |
| Overline | 标签/状态 |

- 不硬编码字号，用系统 token 让主题缩放
- 正文字号 ≥ 16vp，行高 1.5-1.75
- 支持系统字号设置（无障碍），大字号下布局不破
- 数字/价格/计时用 tabular figures

### 色彩与主题

鸿蒙色彩体系，语义化角色 + 暗色模式：

| 角色 | 用途 |
|------|------|
| Primary | 主操作、选中态 |
| On Primary | Primary 上的文字/图标 |
| Container / On Container | 容器背景与前景 |
| Background / On Background | 页面背景与文字 |
| Surface / On Surface | 卡片背景与文字 |
| Error / Warning | 错误/警告 |

- 品牌色注入到 Primary 槽
- 暗色模式：降饱和提亮度，不反色，独立验证对比度
- 功能色配图标，不仅靠颜色

### 触控与手势

- 触控目标 ≥ 48×48vp，间距 ≥ 8vp
- 不依赖 hover，主交互用点击
- 按压反馈：状态层（hover 8% / pressed 12%）100ms 内出现
- 不重定义系统手势（边缘返回、多任务、通知下拉）
- 支持系统手势导航，返回有过渡动画
- 触觉反馈用于确认/重要操作，不过度

### 组件

鸿蒙组件体系，优先用系统原生组件：

- **Button**：Capsule / Circle / Normal，按场景选用
- **List / Grid**：信息列表与网格，支持分组与吸顶
- **Tab**：底部/顶部 Tab，≤ 5 项
- **Sheet**：半模态/全模态，下拉关闭
- **Dialog**：基础/自定义/确认弹窗，危险操作用 Error 色
- **Picker**：时间/日期/文本选择器
- **Slider / Switch / Stepper**：系统样式
- **Navigation**：分栏导航（大屏）/ 单栏（手机）

### 多设备自适应（一多）

鸿蒙核心能力，同一界面跨设备适配：

| 设备 | 策略 |
|------|------|
| 手机 | 单列，底部导航 |
| 折叠屏 | 内屏双列，外屏单列，铰链处避让 |
| 平板 | 分栏导航，内容双栏 |
| 智慧屏 | 大字号，远距离可读，方向键导航 |
| 手表 | 圆形/方形屏，极简信息，侧边旋钮 |
| 车机 | 横屏大字号，语音优先，减少交互步数 |

- 布局自适应：断点（sm/md/lg/xl）决定列数与组件尺寸
- 交互自适应：触控设备用手指目标，车机/智慧屏用方向键焦点
- 资源自适应：按设备密度/形状提供不同资源
- 分布式流转：界面状态可在设备间无损迁移

### 服务卡片设计

鸿蒙特有能力，将应用核心功能以卡片形态置于桌面/服务中心：

| 卡片类型 | 尺寸 | 用途 |
|---------|------|------|
| 小卡片 | 2×2 | 单信息（天气/时钟） |
| 中卡片 | 2×4 / 4×2 | 信息 + 单操作 |
| 大卡片 | 4×4 | 信息 + 多操作 |

- 卡片须自包含：无需进入应用即可完成核心操作
- 信息密度适中，留白充足，不堆砌
- 卡片刷新频率合理，不耗电
- 支持亮/暗色双主题
- 不承载复杂交互，复杂操作引导进入应用

### 无障碍

- 屏幕朗读（TalkBack/随选朗读）：无障碍标签，阅读顺序一致
- 字号设置：大字号下布局不破
- 减弱动效：动画降级
- 高对比度：系统可切换，验证对比度
- 对比度：正文 ≥ 4.5:1，大字 ≥ 3:1

## 资源规格

### 应用图标

| 规格 | 尺寸 |
|------|------|
| 桌面启动图标 | 162×162px |
| 分层前景 | 162×162px（核心元素内缩安全区） |
| 分层背景 | 162×162px（铺满） |

- 图标为前景 + 背景分层，系统按形状裁切
- 安全区：核心元素内缩，避开裁切
- 不含透明背景，用纯色填充
- 提供多分辨率版本

### 启动图

- 按华为应用市场与系统要求生成
- 支持刘海/挖孔安全区
- 背景非纯白/黑，传达品牌识别
- 简洁高级，不含大量文字
- 不误导为系统界面

## 验收标准

- [ ] Tab ≤ 5 项，图标 + 文字
- [ ] 触控目标 ≥ 48vp，间距 ≥ 8vp
- [ ] 状态层（hover/pressed）已实现
- [ ] 多设备自适应：至少覆盖手机 + 一种大屏设备
- [ ] 折叠屏铰链处无可交互元素
- [ ] 服务卡片（若有）自包含，操作闭环
- [ ] 暗色模式独立验证对比度通过
- [ ] 色彩角色已定义，无裸 hex
- [ ] 屏幕朗读标签完整
- [ ] 字号设置大字号下布局不破
- [ ] 应用图标前景 + 背景分层齐全
- [ ] 启动图支持安全区，背景非纯色

## 边界与不做项

- 不负责 iOS/Apple HIG 规范（见 `specs/mobile/ios.md`）
- 不负责 Android/Material 规范（见 `specs/mobile/android.md`）
- 动效原则与 Token 见 `specs/motion/motion-design.md`，本文件仅补充鸿蒙平台差异
- 品牌视觉基线见 `specs/brand`，本文件仅定义鸿蒙平台适配
- 分布式流转的代码实现由开发负责，本规范止于设计交付
- 智慧屏/手表/车机的深度交互规范按华为官方文档补充，本文件提供基线
